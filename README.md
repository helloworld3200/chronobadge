# chronobadge
> Simple GitHub profile badge that displays how long you've been a user for. Easy setup, auto-updates daily through Github Actions!

WORK IN PROGRESS right now!

Will release a full tutorial on how to setup when this is done.

tldr: run cb.py with your username & desired args daily (or in whatever time period youd like for it to update) e.g. by the use of a gh actions workflow; 
the URL of the outputted image which will be in your repo can be used on your profile readme, or anywhere else you want!
